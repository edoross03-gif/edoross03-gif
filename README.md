## Featured

| Project | What it does | Stack |
|---|---|---|
| [**finance-automation**][repo-finance] | The platform I shipped at Kolme: 11 Python scripts that bridge SAP S/4HANA, the Italian e-invoicing system (SDI), a payment provider and bank and factoring files. Colleagues who don't code run them from a local web dashboard. About 65 hours of manual work removed a month. | Python · pandas · Flask |
| [**jobradar**][repo-jobradar] | The system I use to find my next role. Every two hours it polls the career boards of the companies I chose through 24 job-board adapters, filters for early-career roles, scores each match against my profile with an LLM and alerts me on Telegram. | Python · Postgres · Docker · Gemini |
| [**investment-tracker**][repo-tracker] | Work in progress. A P&L engine for a multi-broker portfolio (positions, FX, time-weighted return, Streamlit dashboard), being rebuilt as a web app with Revolut and Crypto.com statement parsers and live prices. | Python · Streamlit · React · Supabase |
| [**personal-site**][repo-site] | [edoardorossetti.eu][site]: the long version of my CV, with a receipt next to most claims and my own habit data behind the hero. One page, assembled by a Python build script, updated nightly by an n8n job. | Python · n8n · Caddy |
